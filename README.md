# Customer Churn Analysis

An end-to-end data analytics project using SQL, Python, Excel, and Power BI to understand customer churn, explore retention patterns, and identify opportunities for better customer retention.

## Project Overview

Customer churn occurs when customers stop using a company's products or services. Understanding churn patterns helps businesses investigate customer dissatisfaction, monitor retention, and make better decisions.

This project analyzes customer data to examine churn, customer tenure, revenue trends, contract types, and customer segments. It combines data cleaning, SQL analysis, Python-based exploratory data analysis, KPI tracking, and an interactive Power BI dashboard.

## Business Objectives

- Analyze customer churn and retention patterns.
- Understand churn across customer segments and contract types.
- Examine relationships between customer tenure, churn, and revenue.
- Track key performance indicators through an interactive dashboard.
- Translate analytical findings into actionable business recommendations.

## Tools and Technologies

- **SQL:** Data querying, aggregations, joins, and KPI calculations.
- **Python:** Data cleaning and exploratory data analysis using Pandas and NumPy.
- **Excel:** Data inspection, validation, and supporting analysis, where applicable.
- **Power BI:** Interactive dashboards, KPI cards, data modelling, and visual reporting.

## Project Workflow

1. **Data preparation:** Inspect the source data and identify missing values, duplicates, and data-quality issues.
2. **Data cleaning:** Apply appropriate cleaning and validation steps.
3. **SQL analysis:** Query the data to investigate churn patterns and calculate relevant metrics.
4. **Exploratory analysis:** Use Python to examine distributions, customer segments, and trends.
5. **Dashboard development:** Build a Power BI dashboard to present important KPIs and findings.
6. **Business recommendations:** Translate the results into practical retention opportunities.

## Key Performance Indicators

The analysis and dashboard cover relevant metrics such as:

- Total customers
- Churned customers and churn rate
- Customer lifetime value (CLTV)
- Customer tenure
- Churn score, where available
- Churn patterns by contract type and customer segment
